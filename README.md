# QuoreStack

Portfolio platform for **Quoreeb Adebayo** — Full Stack Developer.

- Web project showcase
- Mobile app distribution (signup-gated APK downloads)
- Admin CMS powered by Supabase

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment

Copy `.env.example` to `.env` and fill in Supabase keys. See `doc/` for the full implementation plan.
